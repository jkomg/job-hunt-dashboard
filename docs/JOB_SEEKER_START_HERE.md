# Job Seeker Start Here

This is the shortest useful way to start using Job Hunt well.

You do not need to fill in every field or set up every feature on day one.

## The 4 Things To Start With

### 1. Open `Briefing`

This is your daily home base.

Use it to answer:

- what needs attention today
- what follow-ups are due
- whether any roles or interviews need action

If `Briefing` looks empty at first, that is normal. It gets more useful as you add jobs, people, dates, and daily check-ins.

### 2. Add your active jobs to `Pipeline`

Start with the roles you are already seriously tracking.

For each role, you only really need:

- company
- role
- stage
- next action
- next action date or follow-up date

Simple rule:

- use `Next Action Date` when you already know what you plan to do
- use `Follow-Up Date` when you are waiting on someone else and want a reminder if nothing happens

### 3. Add your important people to `Outreach`

Use `Outreach` for:

- recruiters
- hiring managers
- alumni
- referral contacts
- anyone you want to remember to follow up with

You do not need to classify everything perfectly at first.

Good starter fields are:

- name
- company
- next follow-up
- next action

You can refine warmth, status, and relationship details later.

### 4. Use `Check-in` at the end of the day

This is what makes tomorrow easier.

Log:

- outreach sent
- applications submitted
- responses
- one quick reflection
- tomorrow's top 3

Your Top 3 should be specific.

Good:

- Follow up with recruiter at Acme
- Submit BrightPath application
- Send two alumni outreach notes

Too vague:

- Job search
- Networking

## What To Ignore On Day One

It is completely fine to skip these until later:

- Google Sheets sync
- advanced role details
- relationship classification details
- templates
- watchlist
- BYO agent setup

Those features are useful, but they are not required to get value from the app.

## The Daily Rhythm

Use this simple loop:

1. Morning: open `Briefing`
2. During the day: update `Pipeline` and `Outreach`
3. End of day: complete `Check-in`

That is the core workflow.

## If You Forget Where Something Goes

- `Pipeline` = jobs
- `Outreach` = people
- `Interviews` = scheduled interview conversations
- `Events` = networking events, meetups, webinars, job fairs
- `Watchlist` = companies you care about before they become active applications
- `Inbox` = staff or program messages

## What “Good” Looks Like

You are using the app well if:

- `Briefing` shows real priorities
- every active role has a next step
- important people have follow-up dates
- your `Check-in` sets up tomorrow clearly
